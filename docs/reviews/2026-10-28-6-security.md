## 2. Threat model

Unchanged from this morning's report, section 2, with two boundaries added:

- Cloudflare Turnstile, reached from a `WebView` in the app that loads `challenges.cloudflare.com` under the origin `barry.support`, posting its token to the app. Supabase Auth verifies the token with the secret; the app only passes it on.
- Apple Maps, which receives the typed destination and the phone's last known position through `MKLocalSearch` while the Adventurer types.

## 3. Findings

### SEC-1 · The cached Adventure, the Trail buffer and the Check-in queue sit in a file that iOS backups include

**Low** · CWE-312, CWE-922 · MASVS-STORAGE-1, OWASP Mobile Top 10 2024 M9 · **certain** for the storage

**Where:**
- `src/lib/storage.ts:1-3`: `import 'expo-sqlite/localStorage/install'; export const storage = localStorage;`
- `src/lib/barry/adventure-cache.ts:14`, `src/lib/barry/trail-buffer.ts:34`, `src/lib/barry/check-in-queue.ts:25` read and write through it: the destination, the Deadline, the contacts' names and addresses, the last position, up to `MAX_SLOTS` Trail readings and the waiting Check-ins.

**Attack path:** someone with an unencrypted Finder backup, the victim's iCloud backup or a jailbroken phone reads `Documents/SQLite/ExpoSQLiteStorage`.

**Gain:** where the Adventurer is headed and when they are due back, their contacts' addresses, and the last day of their Trail. Unlike this morning, no session: `keychain-session.ts:24-25` moves it out of this file on the first read and `removeItem` deletes the copy.

**Source:** OWASP MASVS-STORAGE-1.

**Fix:** keep these three values in the Keychain as well, or exclude the file from backup.

**Outcome:** skipped, rule 2. The author accepts the storage as it is: the three values stay where they are.

## 4. Hardening notes

New:

- `src/components/captcha.tsx:38`: `originWhitelist={['https://*', 'about:srcdoc']}` lets the Turnstile `WebView` navigate to any https page, and `onMessage` takes a token from whatever page posts one. A forged token gains nothing, because Supabase Auth verifies every token with the secret; narrowing the list to `https://challenges.cloudflare.com` and `about:srcdoc` would keep the view on Turnstile. **Fixed** f39d288 at the author's request: the list is now `barry.support` (the page's own base address), `https://challenges.cloudflare.com` and `about:srcdoc`. react-native-webview matches each entry against the start of an origin only, so a host that begins with `challenges.cloudflare.com.` would also pass. Unverified: Cloudflare is out of reach from this session, so no build has shown that Turnstile loads nothing else.
- `private.guard_contact_count` (`20261028120100_message_limits.sql:26-36`) counts the contacts without a lock, so two inserts in parallel transactions could both see nine. The probe of twenty parallel inserts did not get past ten. At most a few contacts more, each still bound by the five per Adventure and the five Starts.
- `[remotes.hosted.auth.captcha] enabled = false`: until the operator switches it on, sign-ups to arbitrary addresses can still use up `email_sent = 30` per hour, as this morning's note says. The builds with the site key are configured in `eas.json`.
- `src/app/(app)/sign-in.tsx:99`: Check Your Inbox keeps the password in memory until the address is confirmed, as `docs/spec.md:15` intends; it never reaches storage.

Still standing from this morning (section 4 there), unchanged: the default `EXECUTE` on `private` functions; `net` tables readable by `anon` if `net` were exposed; `private.tick_error` after account deletion; a claimed message still going out after its contact is removed; `!==` for `DELIVER_SECRET` (`kick.ts:4`) and the report token (`delivery-report.ts:33`); `minimum_password_length = 6`; `NSAllowsLocalNetworking` in every variant; custom schemes without universal links; `expo-dev-client`'s Metro link; the offline Check-in queue left after Log Out; `.github/dependabot.yml` with `package-ecosystem: ""`; no committed `deno.lock`; Actions pinned by tag; `pages: write` and `id-token: write` on the job that runs `npm ci`; `eas-cli@latest`; `AUTH_SMTP_PASS` uploaded to `deliver`; `sms-relay.mjs` on every interface; `.gitignore` without a plain `.env`; `docs/ci-simulator.md`'s service-role key; the `zod` and `deepmerge` advisories in the Expo CLI.

## 5. Checked and safe

1. **Database:** the limit functions and triggers are `security definer` with `set search_path = ''`; `private.starts` sits in the unexposed `private` schema and cascades on account deletion; `save_adventure` refuses any contact id that is not the caller's own (`unknown_contact`) before it counts them, so neither refusal tells one account anything about another's contacts; the advisors find nothing.
2. **The Trail Map:** unchanged since this morning; the page now has a Content-Security-Policy and sends no referrer (`content-security.ts`, `+html.tsx`).
3. **`deliver`:** refuses a run without `DELIVER_SECRET` (`kick.ts:4`, `kick.test.ts`, `e2e/deliver-refuses-without-secret.e2e.mjs`); the subject and text are bounded by the text limits.
4. **Auth:** the eight-digit code for 15 minutes (`config.toml:234-236`), `secure_password_change = true`, `enable_confirmations = true` in `[remotes.hosted.auth.email]`, `site_url` fixed; Turnstile's token is passed only through `captchaOptions` and verified by Auth.
5. **The app:** the session in the Keychain with `AFTER_FIRST_UNLOCK_THIS_DEVICE_ONLY` (`auth-storage.ts:8`); `turnstilePage` embeds the build-time site key with `JSON.stringify`, so no data from outside reaches the page's script; `turnstileToken` parses the message and takes only a non-empty string.
6. **The web:** `confirmed.web.tsx` reads only the `error_code`, revokes the link's session with `scope=local` and clears the fragment with `history.replaceState`; no `innerHTML` or `dangerouslySetInnerHTML` with outside data.
7. **Secrets:** no secret in the history since this morning; the Turnstile secret is read from `supabase/.env.hosted` by `scripts/hosted-auth.mjs` and never committed.
8. **Supply chain:** MapLibre 6 replaces the vulnerable 5.24.0; the remaining advisories run only at build time.
9. **Documents:** `docs/hosted-supabase.md`'s captcha steps keep the secret out of the repository and switch the captcha on only after the build with the site key ships.
